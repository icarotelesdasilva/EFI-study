The purpose of this project is to explore both 64-bit and 32-bit architectures; essentially, it serves as a study for developing a portable kernel that supports both the i386 and x86_64 architectures. Please do not view this as a "serious" project—it is intended for educational purposes. While it could evolve into something more significant in the future, for now, it is primarily a learning exercise. (Everything released here will always be in a functional state.) There is no AI involved, and the code is not "vibecoded" (i.e., generated by AI prompts)—none of my projects are!
